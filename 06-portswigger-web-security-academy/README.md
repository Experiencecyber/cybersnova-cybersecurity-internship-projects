# Project 6: PortSwigger Web Security Academy Labs

## Project Overview
This project involved completing five Apprentice-level practical labs on PortSwigger Web Security Academy to develop hands-on experience identifying and understanding common web application vulnerabilities.

## Lab Environment
- **Platform:** PortSwigger Web Security Academy
- **Level:** Apprentice
- **Tools:** Web browser, PortSwigger Web Security Academy

## Labs Completed

### 1. SQL Injection – Retrieval of Hidden Data
- Explored how SQL injection can affect application queries.
- Demonstrated how manipulated input can alter the results returned by an application.

### 2. Reflected Cross-Site Scripting (XSS)
- Practised identifying reflected XSS behaviour.
- Examined how untrusted input can be reflected in a web page and potentially executed by a browser.

### 3. Unprotected Admin Functionality
- Identified an administrative path disclosed through the `robots.txt` file.
- Demonstrated the risk of relying on obscurity rather than proper access controls to protect administrative functionality.

### 4. SQL Injection – Login Bypass
- Practised exploiting an SQL injection weakness in a login mechanism.
- Learned how unsafe handling of user input can undermine authentication.

### 5. Information Disclosure in Error Messages
- Examined error messages that exposed application and technology information.
- Identified the information disclosure risk associated with verbose error responses.

## Key Learning Outcomes
- Understanding common SQL injection vulnerabilities.
- Recognising reflected cross-site scripting behaviour.
- Identifying exposed administrative functionality.
- Understanding authentication weaknesses.
- Recognising information disclosure through error messages.
- Appreciating the importance of secure input handling, access controls, and safe error handling.

## Recommendations
- Use parameterised queries and secure database access practices.
- Apply appropriate input validation and output encoding.
- Protect administrative functionality with strong authentication and authorisation.
- Avoid exposing sensitive application information through error messages.
- Conduct regular security testing and remediation.

## Conclusion
Successfully completed five Apprentice-level PortSwigger Web Security Academy labs. The exercises strengthened practical understanding of common web application vulnerabilities and the security measures used to prevent them.

**Skills:** SQL injection awareness, reflected XSS, access control testing, authentication security, information disclosure analysis, web application security testing.
