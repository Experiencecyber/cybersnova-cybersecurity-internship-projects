# CyberSNova Cybersecurity Internship Projects

**Author:** Anayo Okafor  
**Internship:** CyberSNova – Cyber Security  
**Duration:** 1 October – 30 October 2026  
**Domain:** Cybersecurity

## Overview

This repository documents practical cybersecurity projects completed during my four-week CyberSNova Cyber Security Internship in October 2026.

The projects involved network reconnaissance, service enumeration, web directory discovery, network traffic analysis, web application vulnerability assessment, security testing and Linux command-line exercises.

## Projects

### 1. Network Reconnaissance & Service Enumeration
**Tools:** Nmap, cURL, WhatWeb, Kali Linux

Performed authorized reconnaissance against the Nmap practice target to identify open ports, running services, software versions and web technologies.

### 2. Web Directory & File Enumeration
**Tools:** Gobuster, cURL, Kali Linux

Performed directory and file enumeration against an intentionally vulnerable training website, identifying exposed resources and potential information-disclosure concerns.

### 3. Login Traffic Analysis
**Tools:** Wireshark, cURL

Captured and analysed HTTP login traffic in a training environment to examine how credentials could be exposed when transmitted without HTTPS encryption.

### 4. Basic Web Application Vulnerability Assessment
**Tools:** Nikto, Burp Suite Community Edition, cURL

Assessed web server configurations, HTTP security headers, session-cookie attributes and potential information-disclosure weaknesses.

### 5. OWASP Juice Shop Security Assessment
**Platform:** OWASP Juice Shop  
**Tools:** Kali Linux, cURL, Firefox

Assessed a locally hosted vulnerable web application and documented issues involving publicly accessible files, information disclosure, verbose errors, security headers and application metrics.

### 6. PortSwigger Web Security Academy Labs
**Platform:** PortSwigger Web Security Academy

Completed five Apprentice-level labs covering:

- SQL Injection
- Reflected Cross-Site Scripting (XSS)
- Unprotected administrative functionality
- SQL Injection login bypass
- Information disclosure through error messages

### 7. OverTheWire Bandit Levels 0–20
**Platform:** OverTheWire Bandit  
**Environment:** Windows Command Prompt and SSH

Completed the challenge range from Level 0 through Level 20, practising Linux command-line operations, SSH authentication, file permissions, text processing, encoding, compression and network services.

## Skills Demonstrated

- Network reconnaissance and service enumeration
- Web application security assessment
- Vulnerability identification and documentation
- Network traffic analysis
- HTTP request and response inspection
- Linux command-line operations
- SSH and authentication
- Security findings and remediation recommendations

## Learning Outcomes

These projects strengthened my practical understanding of cybersecurity assessment techniques, security weaknesses, evidence collection, technical documentation and remediation recommendations.

## Lab Safety

All activities were conducted against authorized practice targets, intentionally vulnerable training applications or local lab environments for educational purposes.
