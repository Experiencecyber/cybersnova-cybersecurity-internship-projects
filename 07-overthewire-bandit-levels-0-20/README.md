# Project 7: OverTheWire Bandit – Levels 0–20

## Project Overview
This project involved completing OverTheWire Bandit challenges from Level 0 through Level 20 to develop practical Linux command-line skills, understand basic system operations, and practise security-related techniques.

## Lab Environment
- **Platform:** OverTheWire Bandit
- **Levels Completed:** 0–20
- **Environment:** Windows command-line environment with SSH access
- **Tools:** SSH and Linux command-line utilities

## Objectives
- Develop practical Linux command-line experience.
- Practise navigating files and directories.
- Understand file permissions and ownership.
- Learn basic encoding, compression, and data extraction techniques.
- Practise network communication and service interaction.

## Methodology
Connected to the Bandit environment through SSH and worked through the challenges sequentially, using command-line tools to locate and analyse files, inspect data, and solve the exercises.

### Commands and Techniques Practised
- `ssh` – Establishing secure remote connections.
- `ls`, `cd`, `cat` – Navigating directories and reading files.
- `find`, `grep` – Searching for files and specific information.
- `file`, `strings`, `xxd` – Inspecting file types and contents.
- `base64` – Working with encoded data.
- `sort`, `uniq` – Processing and analysing text.
- `gzip`, `bzip2`, `tar` – Handling compressed and archived files.
- `openssl s_client` – Establishing and inspecting TLS connections.
- `nc` – Practising network communication.
- `nmap` – Exploring network service discovery.
- `diff` – Comparing file contents.
- File permission and SUID concepts – Understanding Linux access permissions and privileged execution.

## Key Learning Outcomes
- Improved Linux command-line proficiency.
- Better understanding of SSH and remote system access.
- Practical experience with file discovery and content analysis.
- Understanding of encoding and compression techniques.
- Exposure to network services and encrypted connections.
- Improved understanding of Linux permissions and privilege-related concepts.

## Security Considerations
This repository intentionally excludes Bandit challenge passwords, credentials, and private key material. Only learning activities, techniques, and non-sensitive command examples are documented.

## Conclusion
Successfully completed OverTheWire Bandit Levels 0–20. The exercises strengthened practical Linux skills and introduced important concepts relevant to cybersecurity operations, system administration, and security analysis.

**Skills:** Linux command line, SSH, file analysis, text processing, encoding, compression, network utilities, file permissions, and basic security concepts.
